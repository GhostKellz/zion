# Zig And ZLS Reference

## Zig Version Management

```bash
zion zig install <version>
zion zig use <version>
zion zig use system
zion zig current
zion zig list --remote
```

## ZLS Management

```bash
zion zls doctor
zion zls config
zion zls install
```

## Setup Flow

```bash
zion setup all
zion setup verify
```

## Notes

- `zion setup` is the lightweight onboarding surface
- `zion zig` and `zion zls` are the detailed management surfaces
- Arch Linux workflows remain a first-class target environment
