# Zion Development Roadmap

Current version: **v0.1.4**

## Completed (v0.1.4)

- [x] Hash automation (`hash update`, `hash check`)
- [x] Lock file enhancements (`lock sync`, `lock verify`, `lock clean`)
- [x] Zig native hash format support
- [x] Zig 0.16.0-dev compatibility
- [x] Semver constraint support
- [x] Documentation refresh

## In Progress (v0.1.5)

- [ ] Improved version constraint resolution
- [ ] Transitive dependency handling
- [ ] Better error messages with actionable suggestions
- [ ] Cache optimization

## Planned (v0.2.0)

### Dependency Management
- [ ] Dependency graph visualization
- [ ] Circular dependency detection
- [ ] Optional dependencies support
- [ ] Dev dependencies separation

### Registry
- [ ] Multi-registry support

- [ ] Registry mirroring

### Developer Experience
- [ ] Interactive TUI improvements

### Build System
- [ ] Workspace improvements
- [ ] Build caching
- [ ] Parallel dependency resolution
